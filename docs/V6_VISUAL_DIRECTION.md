# V6 Visual Direction

This file is the shorter implementation companion to `docs/V6_CREATIVE_DIRECTION.md`. The creative direction document is the source of truth for atmosphere, hierarchy, motion, composition, and quality tests; this file summarizes the current visual execution.

## Visual Mood

LK Student Space V6 should feel like a cinematic operating system for a premium dance institution: intimate, polished, calm, and emotionally warm before the user even understands the feature set. The reference point is Apple Fitness / Apple Watch Smart Stack meeting Apple Music campaign rhythm, Nike Training Club confidence, theater backstage lighting, and a boutique wellness club.

The app should never read as a generic dark dashboard. Every major screen needs an editorial anchor: stage light, rehearsal room ambience, velvet/champagne materiality, and a clear emotional focus.

## Component Style

- Surfaces are rounded, soft, layered, and border-light, but not generic glass everywhere. Use velvet depth, champagne rim light, inner light, shadow, and subtle texture overlays.
- Buttons should feel tactile and mobile-native: pill shapes, strong hierarchy, generous tap targets, subtle press motion, no broken gray states.
- Icons live inside elegant capsules or medallions, not loose in generic cards.
- AI and admin panels should look like product operations surfaces, not debug consoles.
- Product and media areas should use art-directed panels when real photography is unavailable: spotlight masks, silhouettes, editorial crops, collection labels, and premium badges instead of blank placeholders.

## Color System

- Base: near-black charcoal with burgundy/velvet undertones and radial stage-light gradients.
- Primary: warm ivory-to-champagne-to-mint action gradient for the main CTA.
- Studio tones: emerald, velvet purple, deep burgundy, champagne gold, refined rose, and platinum violet used sparingly as emotional accents.
- Shop: champagne, amber, cream, soft green, and theatrical product staging for boutique desirability.
- Management/Admin: platinum/violet/sapphire with restrained glow for command-center clarity.
- Avoid random rainbow combinations and flat gray dashboard blocks.

## Typography

- Hebrew RTL first, centered mobile composition.
- Headlines: large, tight, elegant, high contrast, with slight negative tracking.
- Kicker labels: small, spaced, uppercase where Latin is used, and quiet.
- Body text: soft white opacity, short lines, calm hierarchy.
- Numbers and status labels should feel like Apple Watch complications: compact, readable, premium.

## Card Examples

- Hero card: cinematic gradient, soft stage glows, editorial object/silhouette, one emotional headline, one next action.
- Lesson card: compact schedule capsule with style tone, time, room, and a single clear action.
- Shop card: boutique product tile with product image-like stage area, collection language, price capsule, and desirability copy.
- Management card: calm command tile with health metric, next operational action, and quiet urgency.
- Super Admin card: cockpit module with system health, audit, flags, and database counts presented as polished product controls.

## Screen Composition

- Mobile first around 390px: one centered column, dense but breathable, bottom dock always elegant.
- Home should feel like a Smart Stack with an emotional hero anchor: backstage light, key metrics, action capsules, live feed, next item.
- Lessons should feel like a studio schedule, not an admin list.
- Messages should prioritize unread and community warmth.
- Shop should feel like a premium boutique, not a table or product dump.
- More should be a curated control room / product ops cockpit with grouped luxury rows.
- User Management, Private Lessons, Management, and Super Admin should use calm cockpit composition, not raw tables.
