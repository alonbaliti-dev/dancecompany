# V6 Creative Direction

## North Star

LK Student Space V6 is not a dashboard. It is a quiet operating system for a premium dance institution.

The product world should feel like entering the studio before rehearsal: low house lights, warm stage spill, polished floor, backstage calm, disciplined bodies in motion, and a staff that already knows what matters next. Every screen must feel like it belongs to that same evening, that same building, that same artistic culture.

The interface should be useful first, but it should carry atmosphere. It should never feel like assembled Tailwind cards, SaaS widgets, admin panels, or a component demo.

## Emotional Tone

- Calm authority. The app should lower anxiety while making the next action obvious.
- Artistic discipline. The product should feel precise, edited, and rehearsed.
- Belonging. Students and parents should feel held by the studio culture, not managed by software.
- Stage presence. Important moments should have weight, silence, and anticipation.
- Operational trust. Management and Super Admin should feel in command, not inside a debug tool.

Avoid: busy optimism, generic productivity, playful gradients without purpose, notification panic, feature-showcase energy.

## Visual Tone

The visual language is a controlled dark theater:

- Base: near-black charcoal with velvet and burgundy undertones.
- Light: champagne, ivory, soft mint, and rare platinum highlights.
- Accents: emerald, rose, violet, amber, and sapphire only as role or domain signals.
- Material: editorial glass, velvet depth, rim light, and subtle grain. No harsh borders.
- Shape: generous rounded forms, but not toy-like; capsules and medallions should feel crafted.

Every major surface should look lit, not colored. Color is atmosphere and hierarchy, not decoration.

## Depth Behavior

Depth should mimic stage lighting:

- One ambient canvas sits behind the whole app.
- One signature beam or halo gives each hero its emotional center.
- Cards sit in shallow layers, with soft inset highlights and low shadows.
- Admin surfaces can be sharper and more precise, but still polished.
- Never stack multiple unrelated glow systems in the same viewport.

Depth test: if every card is glowing equally, nothing is important.

## Contrast Behavior

Contrast is used to direct attention:

- One primary focal object per screen.
- One primary CTA in the visible scene.
- Secondary actions are quiet glass, not competing buttons.
- Metrics are compact complications, not competing hero cards.
- Empty states are calm notes, not large empty panels.

The app should feel readable in low light. Text can be soft, but action labels and current state must be crisp.

## Imagery Behavior

When real photography is unavailable, use art-directed stage motifs instead of placeholders:

- Light cones, rehearsal-floor arcs, curtain-like gradients, boutique plinths, and crop-like masks.
- Product tiles should feel staged, like objects in a boutique window.
- Media surfaces should feel like studio memories, not upload forms.
- User identity can use initials, but wrapped in medallions and role atmosphere.

Avoid: blank gray boxes, random abstract blobs, stock-dashboard illustration language.

## Typography Philosophy

Hebrew RTL is the primary reading mode.

- Headlines are editorial: large, tight, quiet, and emotional.
- Kicker labels are small, spaced, and cinematic.
- Body copy is short and atmospheric, with operational clarity.
- Numbers behave like Apple Watch complications: compact, confident, immediately legible.
- Avoid over-explaining. Let hierarchy and copy silence create confidence.

Typography test: could this headline appear in a premium dance institution campaign and still explain the product state?

## Composition Philosophy

The app is composed like a scene, not a grid.

- Start with a single emotional anchor.
- Place supporting modules around it in descending importance.
- Prefer asymmetry when it creates focus.
- Use grids only when comparison matters.
- Use horizontal rhythm for quick actions and collections.
- Use vertical rhythm for decisions, messages, and operational review.

Home must feel like one authored moment. It should not read as hero plus metrics plus widgets. Metrics, actions, and AI support the central backstage idea.

## Motion Philosophy

Motion should feel like breath and stage cues:

- Small fades, lift, and press states.
- No playful bouncing.
- No attention-seeking loops.
- Motion supports entry, focus, and confirmation.
- Reduced-motion users get the same hierarchy without animation.

Motion test: would this animation still feel appropriate in a dark theater before curtain?

## Spacing Rhythm

The rhythm is dense but breathable:

- Mobile first at roughly 390px.
- One centered column with controlled side padding.
- Heroes get the most air.
- Supporting cards are compact.
- Groups use 2-3 item clusters before a pause.
- Bottom dock and sticky chrome should feel like part of the same instrument.

Avoid giant empty cards, equal-weight tile walls, and long unbroken admin lists.

## Focus Hierarchy

Each screen must answer:

1. What matters right now?
2. What is the next best action?
3. What can wait?

Screen rules:

- Home: one unforgettable backstage anchor, then compact supporting signals.
- Lessons: next class first, schedule as rehearsal rhythm, not a list.
- Messages: unread and community trust first, not inbox mechanics.
- Shop: boutique curation first, products as staged objects.
- More: calm command center, grouped by operational intent.
- User Management: identity operations cockpit, not a table.
- Private Lessons: concierge coordination, not a form stack.
- Management/Super Admin: product operations cockpit, never debug/admin rawness.

## Luxury Principles

Luxury in LK is restraint, not ornament.

- Fewer competing ideas.
- Fewer equal buttons.
- Fewer borders.
- Fewer colors at once.
- More silence around the important action.
- More craft in the repeated materials.
- More specificity to dance, rehearsal, stage, boutique, and operations.

Luxury test: if everything is loud, the product is not premium.

## Dance And Performance Atmosphere

Use language and visuals from:

- rehearsal readiness
- backstage calm
- stage light
- annual show pressure
- teacher focus
- student progress
- parent trust
- boutique studio culture
- disciplined artistic practice

Do not use generic “dashboard”, “workspace”, “CRM”, “admin”, or “AI panel” language in the UI unless it is truly needed for clarity.

## Quality Test Questions

Before shipping any V6 visual change, ask:

- Does this screen feel authored, or assembled?
- Does it belong to the same night, studio, and product world as the other screens?
- Is there one emotional anchor?
- Is the next action obvious within three seconds?
- Did we remove at least one competing idea before adding another?
- Could this be mistaken for a generic SaaS dashboard?
- Does the screen carry dance, performance, rehearsal, or backstage culture?
- Is management calm and operational, not debug-like?
- Is shop curated and desirable, not a product list?
- Does the UI still work beautifully at 390px RTL without overflow?
- Are handlers, permissions, audit flows, and data paths preserved?
